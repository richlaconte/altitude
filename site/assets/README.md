# Example previews

These JPEGs are screenshots of the repository's actual example apps at commit c995207, using their fictional sample data in Nightfall:

- `support-inbox.jpg`: the first ticket open, with its reply composer.
- `booking.jpg`: initial assessment selected, on the time-selection step.
- `docs-editor.jpg`: the travel policy, details, and version history.

The screenshots were captured at 1280 × 720 through the browser. They are illustrative previews, not customer products. Refresh them when the corresponding example's presentation changes. `scripts/build-site.mjs` embeds their data URLs so the homepage and standalone artifact need no asset host.
